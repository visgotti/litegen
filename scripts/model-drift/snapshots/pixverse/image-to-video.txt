# request property descriptions
model: Video generation model. Access to v5-fast depends on account permissions.
prompt: Generation prompt.
duration: Duration in seconds. C1/V6: 1-15; V5.5/V5.6: 5, 8, or 10; older models: 5 or 8. Do not use unsupported duration/quality combinations.
quality: Output resolution.
seed: Random seed.
webhook_id: Optional ID of a Webhook configured in the same account, not a callback URL. Omit it when polling task status.
img_id: Uploaded image ID. Required for ordinary image generation.
img_ids: Ordered image IDs for a multi-image template only.
template_id: Optional current template ID returned by Get Effect Template List.
generate_audio_switch: Generate native audio with V5.5, V5.6, V6, or C1. Set to true to enable audio or false for silent output.
generate_multi_clip_switch: Enable multi-clip generation with V5.5 or V6. Not supported with other models or template_id.
sound_effect_switch: Legacy sound-effect option; use only with a supporting model/template.
sound_effect_content: Legacy sound description; applicable only when supported.
lip_sync_switch: Legacy Lipsync option; applicable only when supported.
lip_sync_tts_content: TTS text for a supporting legacy Lipsync request.
lip_sync_tts_speaker_id: Speaker ID for a supporting legacy Lipsync request.
