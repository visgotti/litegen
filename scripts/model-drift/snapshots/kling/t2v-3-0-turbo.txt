# field notes
- `prompt`: The content length cannot exceed 3072 characters, and it is recommended that the content length not exceed 2500 characters
- `prompt`: The prompts can be templated to meet different video generation requirements
- `prompt`: > **The Kling 3.0 Turbo model can achieve various capabilities through Prompt and other content.**
  > 1. Multi-shot videos can be generated in a fixed format, with the format being "shot n, m, words; shot n, m, words;", separated by half-width semicolons; where:
  >     a. n: shot sequence number; supports up to 6 storyboards and at least 1 storyboard
  >     b. m: shot duration; each shot duration must be no less than 1 second, and the sum of all storyboard durations equals the total duration of the currently generated video
  >     c. words: shot prompt; maximum length 512
  > 2. For more information, see [Kling VIDEO 3.0 Model User Guide](https://kling.ai/quickstart/klingai-video-3-model-user-guide).
- `settings.resolution`: 720p: output video with a resolution of 720P
- `settings.resolution`: 1080p: output video with a resolution of 1080P
- `options.callback_url`: If configured, the server will actively notify when the task status changes
- `options.callback_url`: For specific message schema, see [Callback Protocol](https://kling.ai/document-api/api/get-started/callbacks)
- `options.external_task_id`: Will not overwrite the system-generated task ID, but can be used for task queries
- `options.external_task_id`: Must be unique within a single user account
- `options.watermark_info`: Defined through the enabled parameter:
- `options.watermark_info`: Custom watermarks are not currently supported
