# field notes
- `contents`: The reference format is as follows, with detailed parameter descriptions provided below:
- `contents[].type.prompt`: English-only input supports up to 26,000 characters, and non-English-only input supports up to 11,000 characters. Mixed input must satisfy E / 26000 + N / 11000 <= 1, where E is the number of English characters and N is the number of non-English characters.
- `contents[].type.prompt`: Defined in JSON format, as follows:
- `contents[].type.prompt`: > **The Kling 4.0 Flash Image-to-Video endpoint uses the first-frame image as the starting point of the video. Use the prompt to describe subsequent character actions, camera movement, and changes in the scene.**
  > 1. **Describe what happens after the first frame.** Specify how characters or objects move and how the scene develops. For example: “The character slowly turns toward the window as the trees outside move backward with the train’s motion.”
  > 2. **Specify actions and camera movement.** Describe camera movements such as pushing in, pulling back, tracking, or panning, and identify the aspects of the characters’ appearance, the setting, and the visual style that should remain consistent. For more details, see the [Kling 4.0 & Kling 4.0 Flash User Guide](https://kling.ai/document-api/api/usage-guide/kling-4-0).
  > 3. **This endpoint supports first-frame-to-video generation only. To combine reference images, videos, or elements, use the Omni Reference Generation endpoint.**
- `contents[].type.first_frame`: Defined in JSON format, as follows:
- `contents[].type.first_frame`: Image format: .jpg, .jpeg, .png.
- `contents[].type.first_frame`: The size of the image file cannot exceed 30MB.
- `contents[].type.first_frame`: The width and height dimensions of the image should not be less than 300px, and the aspect ratio of the image should be between 2:5 and 5:2.
- `contents[].type.first_frame`: Only first-frame-to-video generation is supported.
- `settings.resolution`: 720p: output video with a resolution of 720P
- `settings.duration`: When this parameter is set, its value takes precedence over any duration requested in the prompt.
- `settings.duration`: When this parameter is omitted, the model uses an explicit duration identified in the prompt. For example, "Generate a 15-second video" sets the target duration to 15 seconds.
- `settings.duration`: When this parameter is omitted and no explicit duration is identified in the prompt, the default is 10 seconds.
- `settings.duration`: The final target duration is used to bill the output video. It is returned as usage.output_duration in the task query response and as output_duration in deduction details. Use output_duration when calculating the cost, and apply the corresponding [billing rules](https://kling.ai/document-api/pricing/base/video).
- `options.callback_url`: If configured, the server will actively notify when the task status changes
- `options.callback_url`: For specific message schema, see [Callback Protocol](https://kling.ai/document-api/api/get-started/callbacks)
- `options.external_task_id`: Will not overwrite the system-generated task ID, but can be used for task queries
- `options.external_task_id`: Must be unique within a single user account
- `options.watermark_info`: Defined through the enabled parameter:
- `options.watermark_info`: Custom watermarks are not currently supported
